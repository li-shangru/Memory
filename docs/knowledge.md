# Repository knowledge

Use `./tools/fast-check.sh` while working and `./tools/check.sh --source-only`
for full source verification. The installed gate, `./tools/check.sh`, also
checks the configured installation. See [maintenance](maintenance.md) for
synthetic test guidance and [local delivery](local-delivery.md#what-the-evidence-means)
for evidence from fresh clients and exact artifacts.

The [developer factory knowledge folder](agent-factory/knowledge/) covers
[privacy and runtime identity](agent-factory/knowledge/privacy-runtime.md),
[retrieval provenance](agent-factory/knowledge/retrieval-provenance.md),
[review and approval](agent-factory/knowledge/review-lifecycle.md), and
[MCP contracts](agent-factory/knowledge/mcp-contracts.md).

The maintainer’s Atelier shared knowledge covers `browser-automation.md`, `git-and-github.md`,
`verification-and-artifact-identity.md`, `python-environments-and-synthetic-tests.md`,
and `private-runtime-and-evidence.md`.
